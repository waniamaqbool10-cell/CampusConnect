# Campus Connect

## Project Description
Campus Connect is a simple student website for campus information
and course discovery.

## Features
- Home page for students
- About page describing the project
- Courses page listing learning opportunities
- Shared CSS styling

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub

## Setup Instructions
1. Clone or download this repository.
2. Open the CampusConnect folder.
3. Open index.html in your web browser.
